# 学生信息管理系统（macOS）

一个专为教师设计的本机学生信息管理软件。学生档案、监护人、住宿信息、对应派出所以及关心关爱记录集中管理，**所有数据保存在本机，不上传任何服务器**。

![平台](https://img.shields.io/badge/macOS-14.0+-blue) ![Swift](https://img.shields.io/badge/Swift-SwiftUI-orange)

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 学生档案 | 姓名、学号（自动查重）、是否住宿、联系电话、住宿地址、对应派出所 |
| 监护人 | 每位学生可登记多位监护人（姓名、关系、电话） |
| 自定义字段 | 可自行增删字段（文本/数字/日期/是或否），如班级、性别、出生日期等 |
| 记录系统 | **四类记录**：关心关爱记录、谈话记录、家校沟通记录、违纪记录（默认分类，可自行增删，"恢复默认分类"一键还原）；记录含日期、类别、内容、附件；违纪类别红色标识；记录页按类别筛选（带数量） |
| 附件 | 记录可带附件（照片、Word、PDF…），学生另有独立附件区；支持拖拽导入 |
| 搜索筛选 | 按姓名、学号、电话、家长、派出所及自定义字段全局搜索；按住宿/走读筛选。筛选只在当次会话生效，重新打开或切换数据表后显示全部学生 |
| 显示方式 | 详情 / Excel 式表格随时切换，排序、显示方式、列显隐等个性化设置随项目保存 |
| 快捷筛选标签 | 侧栏"全部 / 住宿 / 走读"标签可自行增删：支持按住宿、按派出所、按自定义字段（如班级）创建，点击即应用筛选 |
| Excel 导入 | 从 .xlsx / .csv 名册批量导入学生：自动识别列、可手动调整映射、可现场新建字段、学号查重（可选覆盖更新） |
| Excel 导出 | 导出前选择内容与**导出范围（当前筛选结果 / 全部学生）**，生成 .xlsx（学生总表 / 监护人明细 / 记录明细——可按类别勾选）；也可导出 CSV 总表 |
| 数据安全 | 启动密码锁（存于本机钥匙串）、闲置自动锁定、自动备份与一键恢复 |

## 快速开始

### 构建应用

需要 macOS 14 及以上 + Xcode（或 Xcode Command Line Tools）。

```bash
cd StudentDB
./build.sh
```

构建产物在 `build/学生信息管理系统.app`，双击即可运行；建议拖入「应用程序」文件夹长期使用。

### 开发调试

```bash
swift run          # 直接运行
swift test         # 运行单元测试
open Package.swift # 用 Xcode 打开工程
```

## 数据是怎么保存的（重要）

每个「项目」是一个独立文件，如 `我的学生库.studentproj`（访达中显示为单个文件，右键 → 显示包内容可查看内部）：

```
我的学生库.studentproj/
├── ProjectInfo.plist    项目基本信息
├── students.json        全部数据（纯文本 JSON，人类可读）
├── attachments/         附件，按 学生/记录 分文件夹
│   └── <学生ID>/files/  该学生的独立附件区
└── backups/             自动备份（保留最近 10 份）
```

**备份与恢复**

- 每次保存时自动在 `backups/` 留快照（同一内容 5 分钟内只留一份，最多 10 份）；
- 设置 → 数据与备份：查看备份列表、一键恢复、在访达中显示；
- 菜单栏「立即备份」可手动强制备份；
- 打开项目时若 `students.json` 意外损坏，软件会自动从最近备份恢复并提示。

**日常维护建议**

1. 定期复制整个 `.studentproj` 文件到 U 盘 / 网盘，即为完整备份（含附件）；
2. 数据是纯文本 JSON，极端情况下可手工查看修复；
3. 学期结束后可另建新项目，旧项目文件归档保存。

**注意**：`backups/` 内的快照只包含数据文件（不含附件）。如需连同附件备份，请复制整个项目文件。

## Excel 导入 / 导出

**导入名册**（菜单：文件 → 从 Excel / CSV 导入学生…，快捷键 ⌘I）

1. 选择 `.xlsx` 或 `.csv` 文件（第一行为列标题）；
2. 软件会自动识别常见列（姓名、学号、是否住宿、电话、地址、派出所、家长信息），每列可手动改选目标，也可选择"＋ 新建字段「列名」"把该列保存为自定义字段；
3. "是否住宿"列支持：住宿/寄宿/是/1 = 住宿，走读/否/0 = 走读；
4. 学号重复的行默认跳过；勾选"学号相同时更新已有学生"可覆盖更新（监护人、自定义字段一并更新，已有关爱记录保留）；
5. 导入完成后显示报告：新增、更新、跳过行及原因。

## 列表显示与筛选

学生列表固定为**一个视图**：筛选条件（搜索关键字、快捷筛选标签、列筛选）只在**当次会话**内生效——重新打开项目或切换到其他数据表再回来，都会显示全部学生；而**排序方式与方向、显示方式（详情 / 表格）、列显隐、列宽**等个性化设置会随项目保存，下次打开保持不变。

- **筛选**：侧栏顶部搜索框按全字段搜索；快捷筛选标签一键按住宿/派出所/自定义字段筛选；表格列头的漏斗可做 Excel 式列筛选（文字包含 + 值清单勾选）。三种筛选可叠加，清除后即回到全部学生；
- **显示方式（详情 / 表格）**：数据区右上角统一位置随时切换。
  - **表格**：像 Excel 一样展示并**直接编辑**全部学生（类型化单元格，参考 Notion 的方案）：文本列**双击就地编辑**（回车保存、Esc 取消），**住宿/是否列单击勾选框直接切换**，**日期列内嵌日期选择器**；点击列标题排序（再次点击反向，排序随项目保存）；顶部”字段”菜单可显示/隐藏任意列；**监护人列按数据库方式扁平展开**（监护人1姓名/监护人1关系/监护人1电话…组数可调，表格与导出一致）；纵向/横向滚动条常显；选中行与左侧列表双向同步；
  - **详情**：左侧选中一位学生，右侧逐项查看其信息、记录与附件。

## 学生记录（四类）

每位学生的"记录"页支持四个默认类别：**关心关爱记录、谈话记录、家校沟通记录、违纪记录**。

- **添加**：记录页右上角 + （当前筛选的类别会自动选为默认类别）；也可从详情页"更多 → 添加记录…"；
- **类别筛选**：记录列表顶部的类别标签带数量（如"违纪记录（2）"），点击只看该类，"全部"看所有；
- **违纪记录**以红色标识提醒；
- **类别管理**：菜单 设置侧的"管理记录类型…"可增删类别，"恢复默认分类…"一键还原为四类（已有记录保留原类别文字）；
- **导出**：导出选择页"记录（按类别勾选）"区可按类别勾选，生成"记录明细"工作表（列：日期、学生、学号、类别、内容）。

## 数据库式表格与字段管理

表格页面向数据库标准看齐，**所有条目可编辑、可修改、可查询**：

- **多选与批量操作**：表格中按住 **⌘ 点选 / ⇧ 连选**多名学生后，工具栏可**批量修改**（选一个字段按类型统一赋值——文本/勾选/日期/下拉/多选，应用到所有选中行，类 SQL `UPDATE ... WHERE 选中`）和**批量删除**（确认后连同记录附件移除）；
- **单元格编辑**：全部数据列（含监护人N姓名/关系/电话、自定义字段）双击就地编辑；格式校验（电话格式、必填、数字/日期类型）三端统一；**下拉选择字段**（如性别）在表格里是下拉菜单，只能选限定选项；
- **列拖拽自由排列**：按住表格**列标题左右拖拽**即可自由排列所有列（内置、监护人、自定义一视同仁，任意交错）；**详情页每行左侧有拖拽手柄**，上下拖拽自由排列字段顺序——两处共享同一布局，改一处全同步；字段管理页 ↑↓ 按钮同样生效；
- **列标题右键菜单**（Notion 式）：按此列升/降序、左移/右移一列、隐藏此列、重命名此字段、删除此字段（**姓名、学号为必备字段不可删除**；其余内置字段与自定义字段均为真删除——连同全部数据一起清除，确认框提示，可从项目备份找回）；
- **字段菜单**（表格工具栏"眼睛"）：顶部**“新建字段…”**可直接在表格页添加字段（8 种类型，下拉/多选可当场填选项）；下方显示/隐藏任意列；学生表单内也可现场添加字段；内置字段与自定义字段统一管理——每行 ↑↓ 调整顺序（表格、详情、导出全部按此顺序）、改名、改类型、编辑下拉选项、删除/恢复；学生表单内也可现场添加字段（支持下拉类型并直接填选项）；
- **查询**：侧栏关键字全字段搜索 + 快捷筛选标签（住宿/派出所/自定义字段/**按任意字段模糊查询**，类 SQL WHERE … LIKE）+ 表格列头漏斗列筛选；排序随项目保存，筛选仅当次会话生效；
- **高度自定义**：自定义字段（文本/数字/日期/是否）、排序与显示方式、列显隐、监护人组数、快捷筛选标签、记录类别均可自行增删改。

## 快捷筛选标签

侧栏搜索框下方的"全部 / 住宿 / 走读"胶囊按钮是快捷筛选标签：

- **点击标签** = 把该筛选条件应用到当前列表（全部标签表示不筛选）；可与上方搜索框叠加使用；
- **"+"按钮**打开管理页：按住宿情况、按派出所（自动列出数据中出现过的派出所）、按自定义字段（如"班级：三（2）班"）创建标签，名称可自定义；
- **删除**：在管理页点垃圾桶图标，或右键侧栏标签选删除；
- 标签全项目共用、随项目保存；删除某个自定义字段时，引用它的标签会自动清理。

**导出数据**（菜单：文件 → 导出数据（选择内容）…，快捷键 ⇧⌘E；也可从侧栏"…"菜单进入）

导出前可选择**导出范围**："当前筛选结果"（只导出当前筛选出的学生，监护人/记录明细也同步过滤）或"全部学生"。再勾选要包含的内容：

- **学生总表**：可单独勾选要包含的自定义字段列；
- **监护人明细**：每位监护人一行（学生、学号、关系、姓名、电话）；
- **关心关爱记录**：日期、学生、学号、类型、内容。

选择后点 **导出 Excel…**（每个勾选项各为一个工作表）或 **导出 CSV…**（仅学生总表，含所选自定义字段列）。另可"导出学生总表 CSV…"（⌘E）快速导出全部字段。注意：附件文件无法放进 Excel，请按上文方式备份项目文件。

**字段类型（8 种，可随时在字段管理页/列头菜单编辑切换）**：文本、数字、日期、**日期时间**、是/否、**单选（下拉）**、**多选**、**地址（多行）**。单选/多选的选项用**条目列表编辑：每行一个选项，＋ 添加、− 删除**（新建字段弹窗与字段管理页一致），单选↔多选互转保留选项；多选在表格中点开勾选菜单、值以顿号拼接；地址在表单中是多行输入。

**数据格式标准**（参考 SQL 约束 / Excel 数据验证，表格、表单、导入三处统一执行）：

- 姓名、学号**必填**（表格里清空会被拒绝），学号全库唯一；
- **电话**：7-15 位数字（可含 +86 或 - 分隔）；"电话不详"等非标准内容会被拒绝，导入时格式不符的行跳过并在报告中说明；
- 自定义字段按类型强校验：数字列仅接受数字、日期列用日期选择器、是或否列用勾选框；
- 导出的 Excel/CSV 中监护人按 **监护人N姓名 / 监护人N关系 / 监护人N电话** 扁平列输出（组数可在导出页选择，最多 4 组），可直接作为标准数据表使用。

## 数据安全

- **启动密码锁**：设置 → 通用 → 开启密码锁。密码的加盐哈希保存在本机「钥匙串」，不会写入项目文件，也不会上传；
- **自动锁定**：开启密码锁后，闲置 5/10/15/30 分钟可自动锁定（可设为从不）；
- **删除保护**：删除学生/记录/附件时移入废纸篓，可在访达恢复；删除学生有二次确认。

> 提醒：密码锁防止的是他人随意打开软件，若数据本身高度敏感，请同时依赖 macOS 账户密码和磁盘加密（FileVault）。

## 常见问题

**Q：忘记密码锁密码怎么办？**
打开「钥匙串访问」App，搜索 `com.monsterisdrinkingwater.studentdb.applock`，删除该项后重启本软件即可重新进入。

**Q：怎么把数据迁移到另一台电脑？**
复制整个 `.studentproj` 文件到新电脑，用本软件「打开项目」即可（新电脑需安装本软件）。

**Q：能多人同时编辑吗？**
不能。数据为本机单用户设计，请避免两人同时编辑同一项目文件。

**Q：可以导入 Excel 名册吗？**
可以。菜单"文件 → 从 Excel / CSV 导入学生…"（⌘I），支持 .xlsx 和 .csv，导入前可核对每列的对应关系。
